# Sharpen

Before starting, consider how a top expert would approach the task, including raw sources, methods, and an independent check of the result. Identify what the user is really after and whether the task is over- or underspecified. Relax incidental constraints only within the user's authorization. Preserve explicit scope, permissions, model preferences, and choices only the user can make. Add only what improves the result, not its size, and keep one independent check. Then do the work without narrating the framing.
