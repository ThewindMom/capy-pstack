# In your own words

Restate what you think the user wants and the problem they are trying to solve, in plain words. Distinguish the desired outcome from a suggested implementation. Preserve their constraints and name uncertainty instead of inventing intent. Use the request and available context, not unrelated history. Do not start implementation or turn the request into a larger task. Stop after the restatement so the user can correct it.
