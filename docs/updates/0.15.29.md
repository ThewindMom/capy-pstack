## Dispositions

- **Sharpen.** `/sharpen` asks for a deeper task, not a bigger one. It lists four asks: what a
  top professional would do that the user did not ask for, the rawest material they would
  start from, their methods and tools, and what other than the agent or the user would show
  the result is right. It then rewrites the prompt and returns only the rewrite. It no longer
  does the task. The native skill keeps the independent check, relaxes constraints only
  within the user's authorization, and preserves explicit scope, permissions, model
  preferences, and choices only the user can make. Upstream `disable-model-invocation`
  stays expressed through the explicit-use description, as in the other explicit skills.
- **Routing and docs.** poteto-help's routing row and recipe, and guide chapters 2 and 10,
  describe sharpening a prompt before sending it, with native paths.
- **Version.** Both upstream manifests move to 0.15.29, recorded as `upstream_version` in
  `pstack.json`.
