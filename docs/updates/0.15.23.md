## Native workflows

`/in-your-own-words` restates the goal before implementation. `/sharpen` applies expert
task framing and an independent check, without loosening explicit authorization or
turning the task into a larger project. Ketchup uses short spoken summaries and small
visuals from observed evidence. Its native thread-history and read-only restrictions remain.

Job-sized reasoning and speed use native model settings rather than Cursor slugs.
Explicit Personal Drive and project policy overrides still win. The example profile
never becomes an override. Verification retains the resolved swarm-worker settings.
Missing models and unsupported controls remain blocking gates, not fallback opportunities.
The unchanged model preset retains its 0.15.15 source identity.

The lifecycle playbooks retain independent verification, current patch evidence, and
scoped approval gates while incorporating the upstream workflow changes. A stale or
stuck writer must be reconciled before replacement. Native callbacks and subscriptions
replace upstream loops. Installation does not authorize publication or merging.

The delegate role can recover a missing skill path from actual session repository or
Drive paths. It follows native discovery precedence, not the highest version on disk.
Cursor activation metadata, menu directions, and Composer-family fallback rules are
not installed.
