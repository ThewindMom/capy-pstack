## Dispositions

- **New skill.** `/create-formal-verification-skill` picks the property where a bug costs
  the most and tests reach the least, verifies it with the tool that fits, and generates a
  project-local skill that rechecks it. The native port writes that skill to
  `.agents/skills/verify-<area>/`, ships it through the repository PR workflow, and keeps
  tool installation on the Capy machine without editing project Setup as a side effect.
  The Cursor `disable-model-invocation` flag is not carried over, as with every native skill.
- **Ketchup.** The reply now lists every item waiting on the user, each with its link,
  user effect, evidence, risk, and pick, so each call is decidable from the reply alone.
  The fixed 150-word cap became a per-item budget. Native thread, task, and PR reads, the
  read-only turn, and attachment rules are unchanged.
- **TypeScript.** A brand comes from a verifying type guard, never from `as`. The pattern
  reference is copied verbatim.
- **Routing and docs.** poteto-help routes formal verification and describes the new
  ketchup. Guide prose edits are ported where the native chapter has the same sentence.
- **Equivalent or platform-only.** Upstream renamed the `poteto-mode` and `make-bot-ui`
  frontmatter names to match their folders, which the native skills already did. The
  Claude Code adapter, rules path, harness-generation note, and Cursor custom-mode anchor
  are platform-only.

## Verification boundary

Repository checks cover packaging, frontmatter, links, inventories, ownership-safe
installation, model resolution, and helper behavior. No helper script changed, so the
Bun tools were not part of this update's required checks. Live skill evaluations were
not run.
