## Dispositions

- **New skill.** `/maintain-formal-verification-skill` finds the commits that touched code a
  formal check covers, updates the model, harness, or properties from the code, reruns, and
  gives each check one outcome: in sync, updated, bug, or blocked. It never weakens a
  property to pass and never edits product code unless asked. The native port looks under
  `.agents/skills/`, runs and installs verifiers on the Capy machine without editing project
  Setup, and ships verification updates only through an authorized repository PR.
- **Formal verification generator.** TLA+ is now the default model checker in any language.
  When no verifier runs on the language, the agent says so and tests the real code with
  generated inputs. Generated skills record covered code and a sync commit, and the handoff
  points at the maintain skill.
- **Setup.** setup-pstack step 8 offers a formal verification skill once when the project has
  none. Declining never blocks setup.
- **Sharpen.** The ban on handing back a rewritten prompt is dropped, as upstream did. The
  native authorization bound and preference preservation are unchanged.
- **Routing and docs.** poteto-help checks for a formal verification skill and routes the
  maintain skill. Recipes add formal verification and ketchup. Guide chapters 1, 2, 6, 7, 9,
  and 10 gain the formal verification, sharpen, in-your-own-words, and ketchup prose with
  native paths.
- **Platform-only parts.** Claude Code install notes, the `~/.claude` rules path, Cursor
  plugin install text, and the Origin CLI watcher are not imported.
