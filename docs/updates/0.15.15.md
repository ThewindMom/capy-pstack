## Native execution is the starting point

A new agent is a new conversation, not necessarily a cloud machine. Shared placement uses
the current runner and checkout. Device placement creates an isolated sibling worktree on
the current computer. Fresh placement creates a cloud machine. Writers prefer isolation;
explicitly coordinated disjoint writers can share a runner without concurrent git writes.
The task validator checks that contract but never starts agents itself.

Plans must declare the observed runner explicitly. Help and recurring audits read the
actual installed bundle, not an older published main branch. These constraints are checked
by regressions because prose-only placement advice missed them during the initial port.

Fresh-agent rounds carry the original brief, later directives, accepted artifacts and
actual branch. Keep a live owner for callbacks, uncommitted work and processes that cannot
be safely transferred. A timeout or a stop request alone does not release ownership.

## Model policy preserves meaning without inventing capabilities

The source now uses Opus 5.5 and Grok 4.7 for its two-seat panels. Opus defaults to xhigh;
Grok handles reflection tooling as well as implementation and exploration. Three
reflection lenses still run before one synthesis. Comment Sicko inherits the parent.

The default capy-native policy preserves those weights and reasoning settings, recording
unsupported fast priority as an explicit native adaptation. Upstream-faithful is the strict
option and rejects unsupported priority. Neither silently substitutes a model. Existing
profiles and explicit pins are preserved, not rewritten into a new spending policy.

## New workflows and publishing boundaries

Benchmark checklist and Explain the Number verify the limiter, tuning, errors,
repeatability, relevance, and actual work behind measurements. Correct fixes repeated
mistake classes through architecture, types, lint, and tests before adding prose.
Poteto help answers routing questions without launching the recommended workflow.

Portable upstream design, audit, perf and build changes are retained. Cursor task APIs,
editor mode controls and local chat databases are replaced with native Capy capabilities.
Work stays uncommitted unless publication is requested. PR creation uses native ownership;
multi-PR stacks use the installed gh-stack workflow. Neither a green test nor a skill
invocation authorizes merging or amendment.

## Evidence boundary

Three native maintenance subagents started on the same shared Mac runner, with disjoint
scopes and no git writes. That is live evidence of same-runner spawning. Unit tests cover
model decisions, placement validation, installation and process behavior. They do not
certify cloud handoffs, device worktrees, cross-provider panels, PR callbacks, or automations.
Keep those gates distinct in the [live smoke checklist](../live-smoke.md).

A later bounded Opus/Grok candidate run and independent Opus cross-judge completed using
native tools. Both candidate artifacts passed the task CLI, and local-placement failure
cases were rejected. The model routes and completion were observed; effective reasoning
and priority were not independently attested. The disconnected-device recovery used
reconstructed candidate inputs, so it is not proof of byte-perfect artifact transfer.
